# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through [GitHub security advisories](https://github.com/Just9OO/900TicketBot/security/advisories/new). Include what you found, how to reproduce it, and the version you tested. You will get a reply as soon as possible.

## Keeping your bot safe

- Never commit `.env`. It is listed in `.gitignore`.
- If your bot token is ever exposed, reset it in the Discord Developer Portal immediately.
- Give the bot only the permissions listed in the README.
